# Anno 117 Arabic Manager

<p align="center">
  <img src="resources/app/assets/roman-background.png" alt="Anno 117 Arabic Manager" width="100%">
</p>

أداة عربية لإدارة تعريب **Anno 117: Pax Romana** بواجهة واحدة.
البرنامج يبني حزمة التعريب من ملفات لعبتك المحلية، ثم يثبتها مع إنشاء نسخة احتياطية قبل أي تعديل.

## التحميل

حمّل النسخة الجاهزة من صفحة الإصدارات:

[تحميل Anno117_Arabic_v1.0.0_Release.zip](https://github.com/Omaralasam/Anno117_Arabic/releases/latest/download/Anno117_Arabic_v1.0.0_Release.zip)

## طريقة التشغيل

1. حمّل ملف `Anno117_Arabic_v1.0.0_Release.zip`.
2. فك الضغط بالكامل في أي مكان مناسب.
3. افتح المجلد الناتج، ثم شغّل `Anno117ArabicManager.exe`.
4. أغلق اللعبة و Ubisoft Connect قبل التثبيت أو الاستعادة.
5. إذا لم يتعرف البرنامج على مكان اللعبة تلقائيًا، اضغط زر الاختيار اليدوي واختر مجلد اللعبة.
6. اضغط **فحص سريع**.
7. إذا كانت الحالة سليمة، اضغط **جهز وثبت التعريب**.

> مهم: لا تشغل البرنامج من داخل ملف ZIP مباشرة. يجب فك الضغط كاملًا أولًا.

## إذا لم يتعرف على مكان اللعبة

اضغط زر الاختيار اليدوي داخل البرنامج واختر مجلد اللعبة نفسه، وليس مجلد `maindata`.

مثال صحيح:

```text
C:\Games\Anno 117 - Pax Romana
```

مثال غير صحيح:

```text
C:\Games\Anno 117 - Pax Romana\maindata
```

## إذا ظهرت مشكلة بعد التثبيت

1. أغلق اللعبة و Ubisoft Connect.
2. افتح البرنامج.
3. اضغط **استعادة آخر نسخة**.

البرنامج يأخذ نسخة احتياطية قبل التثبيت حتى يمكن الرجوع للملفات الأصلية.

## إذا ظهرت رسالة "ملفات ناقصة"

هذا غالبًا يعني أن البرنامج لم يجد بعض الملفات الموجودة معه. يحدث هذا عادةً إذا تم تشغيله من داخل ملف ZIP، أو إذا تم تحميل كود المشروع بدل نسخة البرنامج الجاهزة.

الحل:

1. افتح صفحة **Releases**.
2. حمّل ملف `Anno117_Arabic_v1.0.0_Release.zip`.
3. اضغط **Extract All** أو **فك الضغط**.
4. افتح المجلد بعد فك الضغط.
5. شغّل `Anno117ArabicManager.exe`.

بعد فك الضغط يجب أن ترى بجانب البرنامج مجلدين مهمين:

- `tools`
- `rda-work`

لا تحذف هذين المجلدين، فالبرنامج يحتاجهما ليبني التعريب.

## طريقة عمل الأداة

- لا توزع الأداة ملفات اللعبة الأصلية.
- تقرأ ملفات اللعبة الموجودة على جهازك.
- تدمج ملفات التعريب العربية محليًا.
- تبني حزمة `file_browse_patterns.rda`.
- تحدث `file_h.db / checksum_h.db` أو `file.db / checksum.db` حسب نسخة اللعبة.
- تحفظ نسخة احتياطية قبل أي تعديل.
