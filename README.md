# Anno 117 Arabic Manager

أداة عربية لإدارة تعريب **Anno 117: Pax Romana** من خلال واجهة واحدة.  
تقوم الأداة ببناء حزمة التعريب محليًا من ملفات لعبة المستخدم، ثم تثبتها مع إنشاء نسخة احتياطية قبل أي تعديل.

## التحميل المباشر

حمّل النسخة الجاهزة من هنا:

[Anno117_Arabic_v1.0.3.zip](https://github.com/Omaralasam/Anno117_Arabic/releases/download/v1.0.3/Anno117_Arabic_v1.0.3.zip)

## التحميل والتشغيل

1. حمّل النسخة الجاهزة من صفحة الإصدارات في GitHub.
2. فك الضغط في أي مجلد مناسب.
3. أغلق اللعبة و Ubisoft Connect بالكامل قبل التثبيت.
4. شغّل:

```text
Anno117ArabicManager.exe
```

5. إذا لم يتعرف البرنامج على مكان اللعبة، اضغط **اختيار مكان اللعبة** واختر مجلد Anno 117.
6. اضغط **فحص سريع** للتأكد من أن مسار اللعبة والملفات المطلوبة سليمة.
7. اضغط **جهز وثبت التعريب**.

## إذا لم يتم العثور على مسار اللعبة

انسخ الملف:

```text
game-path.example.txt
```

إلى:

```text
game-path.txt
```

ثم اكتب داخله مسار مجلد اللعبة، وليس مجلد `maindata`.

مثال:

```text
D:\SteamLibrary\steamapps\common\Anno 117 - Pax Romana
```

## الاستعادة

إذا ظهرت مشكلة بعد التثبيت:

1. أغلق اللعبة و Ubisoft Connect.
2. افتح الأداة.
3. اضغط **استعادة آخر نسخة**.

## ملاحظات النشر

- لا يحتوي هذا المستودع على ملفات اللعبة الأصلية.
- المجلدات المحلية مثل `backups/` و `rda-work/` مستبعدة من Git لأنها ملفات توليد ونسخ احتياطية وقد تحتوي ملفات كبيرة أو ملفات لعبة محلية.
- الملفات التنفيذية والثنائية الكبيرة محفوظة باستخدام Git LFS.

## ملفات مفيدة

- `README_AR.md`: شرح عربي تفصيلي.
- `README_NEXUS_AR.md`: وصف مختصر مناسب للنشر في Nexus Mods.
- `install_existing_slot_arabic.ps1`: سكربت التثبيت.
- `restore_existing_slot_arabic.ps1`: سكربت الاستعادة.
