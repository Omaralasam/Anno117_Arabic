# Anno 117 Arabic Manager

أداة عربية بواجهة واحدة لتثبيت واستعادة تعريب **Anno 117: Pax Romana** بطريقة آمنة.

## التحميل

من صفحة الإصدارات:

```text
https://github.com/Omaralasam/Anno117_Arabic/releases/latest
```

أو مباشرة:

```text
https://github.com/Omaralasam/Anno117_Arabic/releases/latest/download/Anno117_Arabic_v1.0.0_Release.zip
```

## الخطوات المختصرة

1. فك الضغط كاملًا.
2. شغّل `Anno117ArabicManager.exe`.
3. أغلق اللعبة و Ubisoft Connect.
4. اختر مكان اللعبة يدويًا إذا لم يتعرف عليه البرنامج تلقائيًا.
5. اضغط **فحص سريع**.
6. اضغط **جهز وثبت التعريب**.

## الاستعادة

إذا ظهرت مشكلة:

1. أغلق اللعبة و Ubisoft Connect.
2. افتح البرنامج.
3. اضغط **استعادة آخر نسخة**.

## ملاحظات مهمة

- لا تشغل البرنامج من داخل ZIP.
- لا تحذف الملفات الموجودة بجانب البرنامج.
- اختر مجلد اللعبة، وليس مجلد `maindata`.
- مجلد `tools\RDAExplorer` مطلوب كملفات داخلية لبناء الحزمة.
- البرنامج لا يحتوي على ملفات اللعبة الأصلية ولا يوزعها.

## إذا ظهرت رسالة "ملفات ناقصة"

حمّل نسخة البرنامج الجاهزة من صفحة Releases، ثم فك الضغط بالكامل، ثم شغّل `Anno117ArabicManager.exe` من المجلد المفكوك.

لا تستخدم زر **Download ZIP** الموجود في صفحة الكود، لأنه يحمّل ملفات المشروع وليس نسخة التشغيل الجاهزة.
