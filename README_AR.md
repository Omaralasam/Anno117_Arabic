# Anno 117 Arabic Manager

أداة محلية بواجهة واحدة لإدارة تعريب **Anno 117: Pax Romana** بطريقة الحزمة المدمجة التي نجحت بعد تحديث اللعبة.

## ماذا تفعل الأداة؟

- تبني `file_browse_patterns.rda` مدمجًا يحتوي ملفات اللعبة الأصلية المطلوبة للإقلاع مع ملفات التعريب العربية.
- تولد قاعدة الفهرس المؤقتة.
- تربط ملفات التعريب بفتحة الأرشيف الحالية داخل `file_h.db` أو `file.db`.
- تثبت الحزمة داخل `maindata` مع إنشاء نسخة احتياطية قبل أي تعديل.
- تستعيد آخر نسخة احتياطية بضغطة واحدة.
- تعرض حالة اللعبة، سلامة checksum، تطابق الحزمة، ونسبة التعريب.

## طريقة الاستخدام

1. أغلق اللعبة و Ubisoft Connect قبل التثبيت أو الاستعادة.
2. افتح `Open_App_No_Console.vbs`.
3. اضغط `جهز وثبّت التعريب`.
4. شغّل اللعبة وافحص التعريب.
5. إذا حدثت مشكلة، أغلق اللعبة واضغط `استعادة آخر نسخة`.

## عند مشاركة الأداة مع شخص آخر

- إذا كانت اللعبة في مسار مختلف، انسخ `game-path.example.txt` إلى `game-path.txt`.
- اكتب داخل `game-path.txt` مسار مجلد اللعبة، وليس مجلد `maindata`.
- مثال: `D:\SteamLibrary\steamapps\common\Anno 117 - Pax Romana`

## ملاحظة مهمة

لا تنشر ملفات اللعبة الأصلية مع الأداة. عند مشاركة المشروع مع الآخرين، شارك الأداة والسكربتات وملفات التعريب فقط، واترك كل شخص يبني الحزمة من ملفات لعبته المحلية.

## الموسيقى والهوية

- الواجهة تحمل عنوان `عام 117: السلام الروماني` وتوقيع `Omar009`.
- زر الموسيقى يشغل ملفًا محليًا إذا وجد داخل `assets\audio` باسم `anno117-theme.mp3` أو `anno117-theme.ogg`.
- إذا لم يوجد ملف موسيقى، تشغل الأداة أجواء صوتية خفيفة مولدة داخل الواجهة.
- لا ترفق موسيقى اللعبة الأصلية في نسخة عامة تنشرها للناس.
