# مسار نصوص شاشة التحذير

ملف التعديل المباشر:

`rda-work/warning_screen_ar.txt`

المسار داخل حزمة اللعبة:

`data/base/config/gui/texts_english.xml`

السطور المهمة:

- `LineId -6905317036886659735`: نص التحذير الرئيسي الطويل.
- `LineId -6913015422949216362`: ملاحظة اللعب المشترك بين المنصات.
- نص العنوان `WARNING: READ BEFORE PLAYING` يترجم داخل سكربت البناء إلى: `تحذير اقرأ قبل اللعب`.

طريقة العمل:

1. نعدل النص العربي في `warning_screen_ar.txt`.
2. سكربت البناء يحوله تلقائيًا إلى صيغة اللعبة ويضع فواصل الأسطر.
3. يتم حقنه داخل `texts_english.xml`.
4. يتم بناء الحزمة الآمنة وتثبيتها في `file_browse_patterns.rda`.
