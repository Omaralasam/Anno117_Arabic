# عام 117: السلام الروماني - التعريب العربي

هذه نسخة نشر نظيفة مخصصة لـ Nexus Mods.

## مهم قبل التثبيت

- أغلق اللعبة بالكامل.
- أغلق Ubisoft Connect من الخلفية أيضًا.
- لا تنسخ ملفات يدويًا إلى `maindata`.
- شغّل البرنامج واضغط: **جهز وثبّت التعريب**.

## طريقة العمل

البرنامج لا يوزع ملفات اللعبة الأصلية. بدل ذلك:

1. يقرأ ملفات اللعبة الموجودة على جهازك.
2. يدمج ملفات التعريب العربية معها محليًا.
3. يبني حزمة آمنة باسم `file_browse_patterns.rda`.
4. يحدث `file_h.db` / `checksum_h.db` أو `file.db` / `checksum.db` حسب نسخة اللعبة.
5. يأخذ نسخة احتياطية قبل أي تعديل.
6. يثبت التعريب داخل مجلد `maindata`.

## التثبيت

1. فك الضغط عن الملف.
2. افتح:

```text
Anno117ArabicManager.exe
```

3. اضغط **فحص سريع**.
4. إذا كانت الحالة سليمة، اضغط **جهز وثبّت التعريب**.
5. شغّل اللعبة.

## إذا لم يجد البرنامج مسار اللعبة

أنشئ ملفًا باسم:

```text
game-path.txt
```

بجانب البرنامج، واكتب داخله مسار اللعبة، مثال:

```text
D:\SteamLibrary\steamapps\common\Anno 117 - Pax Romana
```

## الاستعادة

إذا ظهرت مشكلة بعد التثبيت:

1. أغلق اللعبة و Ubisoft Connect.
2. افتح البرنامج.
3. اضغط **استعادة آخر نسخة**.

## ملاحظات النشر

- هذه الحزمة لا تحتوي على `file_h.db` أو `checksum_h.db` أو `file_browse_patterns.rda` جاهزة من ملفات اللعبة.
- هذه الملفات تُبنى عند المستخدم محليًا لتجنب مشاكل اختلاف إصدارات اللعبة.
- إذا نزل تحديث جديد للعبة، يفضل تشغيل البرنامج مرة أخرى وبناء التعريب من جديد.
